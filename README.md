rm-out
======

### _A better way to delete files._

Have you ever wished to be forcibly ejected from your flow-state at random points throughout the day? Of course you have! `rm-out` will randomly turn your `rm` commands into games of breakout where each block is a file. There is no way to skip it, so I hope you didn't use `-r` on a big tree.

Installation
------------
Download binaries from the release page, compiled by me, a random internet person! We encourage you to install them in `/bin/` and place an `alias rm='rm-out'` in `/etc/profile` for maximum damage.

I _totally_ did not accidentally delete the `.git` three times in the process of writing this program.

Cheers, and remember: **The best bytes, are _no bytes_!**
